# 08 - SQL Subqueries

## Objective
Master nested SQL logic used for comparison, filtering, and advanced analysis.

## Topics Covered
- Scalar subqueries
- Multi-row subqueries
- Correlated subqueries
- Subquery in FROM
- IN / EXISTS / NOT EXISTS

## Files
- `setup.sql` → tables and sample dataset
- `notes.md` → subquery concepts and rules
- `problems.sql` → core practice questions
- `problems_scenarios.sql` → business scenario questions

## Why this topic matters
Subqueries are common in:
- interviews
- analytics
- ETL checks
- business reporting
- data validation

## Key Learnings
- Compare a value against another query result
- Find missing records
- Compare row behavior against group behavior
- Write nested logic cleanly

## Common Mistakes
- Using the wrong comparison operator
- Forgetting alias in derived tables
- Mixing row-level and group-level logic
- Using `NOT IN` carelessly with NULLs
