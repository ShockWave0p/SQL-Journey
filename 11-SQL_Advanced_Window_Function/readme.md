# 📘 11 - Advanced Window Functions

---

## 🎯 Objective

Learn advanced analytical SQL using window functions for:

* row-to-row comparison
* moving averages
* ranking behavior
* frame-based calculations

---

# 📌 Topics Covered

* `LAG()`
* `LEAD()`
* `FIRST_VALUE()`
* `LAST_VALUE()`
* `NTILE()`
* `ROWS` frames
* `RANGE` frames
* Running totals
* Moving averages

---

# 🧠 Why This Topic Matters

Advanced window functions are heavily used in:

* analytics engineering
* trend analysis
* financial reporting
* dashboards
* time-series SQL

---

# 🚀 Key Learnings

* Previous vs next row comparisons
* First/last value logic
* Bucket analysis
* Moving averages
* Cumulative totals
* Window frame control

---

# ⭐ Most Important Concept

Window functions analyze rows without collapsing them.
