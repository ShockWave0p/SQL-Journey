# 04 - SQL Aggregations (GROUP BY, HAVING)

## 📌 Objective

Learn how to summarize and analyze data using SQL aggregation functions.
This topic focuses on transforming raw data into meaningful insights.

---

## 📚 Topics Covered

* Aggregate Functions: `COUNT()`, `SUM()`, `AVG()`, `MIN()`, `MAX()`
* `GROUP BY`
* `HAVING`
* Difference between `WHERE` and `HAVING`

* How to group data using `GROUP BY`
* How to calculate metrics like total revenue, average values, and counts
* When to use `WHERE` vs `HAVING`
* How to filter aggregated results
* Writing multi-condition aggregation queries

## ⚠️ Common Mistakes

* Using `WHERE` instead of `HAVING` for aggregated conditions ❌
* Forgetting to include non-aggregated columns in `GROUP BY` ❌
* Mixing row-level and group-level logic ❌
